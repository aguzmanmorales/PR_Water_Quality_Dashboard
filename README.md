# Puerto Rico Remotely Sensed Water Quality Dashboard

**Live Dashboard:** [View the Dashboard Here](https://aguzmanmorales.github.io/PR_Water_Quality_Dashboard/)

## Overview
Climatologies and Anomalies of Sentinel-3 OLCI imagery (2016-2026) water quality products (Chl-a, Kd490, and TSM_NN) processed for Puerto Rico. 

For more information about these products, please refer to the [Sentinel-3 Ocean Colour Level-2 Data Guide](https://user.eumetsat.int/resources/user-guides/sentinel-3-ocean-colour-level-2-data-guide).
